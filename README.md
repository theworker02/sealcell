# sealcell

Seal digests and cell fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/sealcell/

## Install / run

```bash
git clone https://github.com/theworker02/sealcell.git
cd sealcell
node src/cli.js
node --test
```
